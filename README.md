# Nawrah Qanita Irfan — Portfolio

A fresh Next.js project with a cinematic intro: growth-chart particles **morph into the name**, followed by gray iMessage-style typing capsules **transforming into blue spring-bounce navigation bubbles**.

## Start on Windows (VS Code)

1. Extract the ZIP to a new folder (not inside the old portfolio).
2. Open the `nawrah-portfolio` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Visit http://localhost:3000.

## Edit

- `app/page.tsx`: text, timings, canvas morph and bubble animations.
- `app/globals.css`: background, spacing, fonts, mobile design.
- `public/blue-reference.png`: background texture based on the supplied Canva reference.

The two category pages currently contain **illustrative project placeholders**, not completed case studies. Replace with verified project details and results before applying.

## Deploy

Push to GitHub, then import the repository into Vercel. Framework: Next.js; default build settings work.
